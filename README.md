# MohammedLab PS3

مشروع برنامج Windows عام لأجهزة الكمبيوتر المتوافقة مع متطلبات RPCS3، بواجهة عربية وإنجليزية وتجربة إعداد سهلة.

## حالة المشروع

تم تجهيز تعليمات التنفيذ ومهمة بناء الإصدار الأول. لا يحتوي المستودع حاليًا على محاكي مبني أو نسخة EXE جاهزة، ولا يعني تجهيز المهمة نجاح تشغيل الألعاب.

## مهمة الأيجنت

اقرأ [AGENTS.md](AGENTS.md) ثم [مهمة التنفيذ الكاملة](docs/IMPLEMENTATION_TASK.md).

المطلوب استيراد مصدر RPCS3 الرسمي على commit محدد، وبناء الأساس أولًا، ثم إضافة الواجهة والإعداد والتشخيص وتجميع ZIP لويندوز. يجب الحفاظ على حقوق المصدر وتراخيصه.

## التشغيل المستهدف

فك الضغط ← فتح EXE ← فحص الجهاز ← تثبيت firmware محليًا ← إضافة اللعبة ← اختيار وسيلة التحكم ← تشغيل.

التوافق والأداء يعتمدان على مواصفات الكمبيوتر واللعبة. لا توجد وعود بتشغيل جميع الألعاب على جميع الأجهزة.

## المصادر

- RPCS3: https://github.com/RPCS3/rpcs3
- متطلبات الأجهزة: https://rpcs3.net/requirements
- firmware الرسمي: https://www.playstation.com/ar-sa/support/hardware/ps3/system-software/

ملفات الألعاب وfirmware والتراخيص الخاصة بالمستخدم لا تُرفع إلى المستودع.
