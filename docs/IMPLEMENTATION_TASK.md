# مهمة تنفيذ MohammedLab PS3

المستودع المستهدف: https://github.com/moha700m/Ps3
الفرع الأساسي: main

## الهدف
نفّذ برنامج Windows أصليًا مبنيًا من مصدر RPCS3، باسم MohammedLab PS3، بواجهة عربية وإنجليزية وتجربة إعداد سهلة. التطبيق عام لأجهزة الكمبيوتر التي تحقق متطلبات المحرك، وليس مخصصًا لجهاز أو مصنع CPU/GPU أو يد معينة. لا تعد بتشغيل جميع الألعاب على جميع الأجهزة.

## المرحلة الأولى: أساس يبني فعلًا
1. اقرأ AGENTS.md والمستودع الحالي واحفظ تعليمات هذا المشروع عند استيراد المحرك.
2. اعتمد https://github.com/RPCS3/rpcs3 فقط مصدرًا للمحرك. اختر upstream commit كاملًا وثبته مع recursive submodules.
3. استورد المصدر داخل المستودع الحالي، دون حذف تاريخ هذا المستودع أو الكتابة فوق تعليماته بلا دمج.
4. وثّق commit والإصدارات في upstream.lock أو ملف مماثل وdocs/BUILDING.md.
5. اقرأ README وLICENSE وBUILDING.md وCMakeLists.txt و.github/workflows/rpcs3.yml و.ci عند commit المثبت.
6. ابنِ Release x64 من المصدر غير المعدل قبل تغيير الواجهة. حافظ على PPU/SPU/RSX/JIT وأنظمة الرسوم والصوت والإدخال وتثبيت firmware والألعاب.
7. استخدم C++ وQt والأدوات المطابقة للوثائق الحالية للمراجعة المثبتة. أدوات التطوير تبقى في بيئة البناء.
8. جهّز workflow Windows للبناء والاختبارات ورفع artifacts، ثم تابع المراحل التالية. إذا لم تكف جلسة واحدة، سلّم PR ملموسًا يحقق هذه المرحلة مع نتائج التحقق، ثم وثّق العمل المتبقي بدقة. لا تختصر المحاكاة إلى واجهة وهمية.

## المرحلة الثانية: واجهة وإعداد عام للأجهزة
استخدم واجهة Qt القائمة وربطها الفعلي بالمحرك.
- عربية RTL وإنجليزية مع إبقاء المسارات والمعرّفات التقنية سليمة.
- شاشة أول تشغيل: فحص الجهاز ← تثبيت firmware ← إضافة اللعبة ← إعداد التحكم ← تشغيل.
- مكتبة ألعاب من ملفات المستخدم الفعلية، بالاسم والمعرّف والصورة المحلية عند توفرها، والبحث والتشغيل والإيقاف والإعدادات.
- إعدادات الرسوم والصوت والتحكم وإعدادات مستقلة لكل لعبة باستخدام آليات RPCS3 الموجودة، مع استعادة الافتراضي.
- صفحة تشخيص وسجلات وتصدير تقرير محلي يختاره المستخدم.
- حفظ الإعدادات وملفات الحفظ والكاش في مسارات قابلة للكتابة، وحفظ بيانات المستخدم عند التحديث.

افحص تلقائيًا OS ومعماريته وCPU وتعليماته المطلوبة وRAM وGPU المتاح ودعم Vulkan/OpenGL ومساحة التخزين وصلاحية الكتابة وأجهزة التحكم.
قارن النتائج بمتطلبات commit المثبت، واعرض سبب عدم التوافق أو الحاجة لتعريف أو إعداد مناسب.
ادعم Windows 10 وWindows 11 x64 فقط بقدر ما تدعمه مراجعة المحرك المثبتة؛ وثّق أي تضييق حقيقي في المتطلبات.
اجعل البناء عامًا لمعالجات Intel وAMD التي تحقق متطلبات المحرك. تجنب خصائص تجميع تربطه بمعالج جهاز البناء، ولا تخفض متطلبات تعليمات المحرك دون تنفيذ واختبار فعليين.
ادعم NVIDIA وAMD وIntel عبر backends المحرك المتوافقة. اختر Vulkan عند توفره، وأتح OpenGL عند دعمه. في الأجهزة متعددة GPU اعرض الخيارات واحفظ اختيار المستخدم.
ابدأ بدقة العرض الأصلية وإعدادات المحرك الافتراضية. رفع الدقة اختياري، ولا تفرض 4K أو 60 FPS أو تغييرات عشوائية في دقة المحاكاة.
أي تعديل خاص بلعبة يرتبط بمعرفها ويوثق سبب استخدامه، مع استعادة الافتراضي.

## التحكم
استخدم handlers الأصلية ودعم لوحة المفاتيح وDualSense وDualShock وXInput حيث يدعمها المحرك.
اعرض اسم الجهاز والhandler وحالة الاتصال، واختبار الأزرار والعصي والمحفزات عند توفرها، وتعديل التعيينات وحفظها.
تعامل مع الفصل وإعادة التوصيل. وجود يد معينة ليس شرطًا لفتح البرنامج.
لا تفرض تحويل اليد إلى Xbox افتراضي، ولا تثبت تعريفات أو برامج تحكم إضافية تلقائيًا.

## ملفات المستخدم
أضف زر فتح صفحة Sony الرسمية، واختيار PS3UPDAT.PUP محليًا وتثبيته باستخدام مثبت RPCS3 مع التقدم ورسائل الفشل.
استورد مجلدات أقراص PS3 المدعومة مثل PS3_GAME وحزم PKG بالآليات الموجودة بعد التحقق من متطلبات التنسيق في المراجعة المثبتة.
عند حاجة المحتوى لترخيص، أتح استيراد ملف المستخدم المحلي وفق آلية المحرك.
لا ترفع firmware أو ألعابًا أو مفاتيح تراخيص إلى git أو ZIP أو CI، ولا تبحث عن نسخ ألعاب أو تولّد مفاتيح.
دعم ISO أو أي تنسيق آخر يحتاج تحققًا من الوثائق والكود والاختبار.
اعرض تقدم تجهيز shaders بصورة مفهومة.

## المرحلة الثالثة: التسليم والاختبار
أنشئ Actions على pull_request وworkflow_dispatch للبناء والاختبارات المتاحة.
راجع upstream CI قبل تكييفه: عدّل شروط repository/branches والرفع حتى يعمل في moha700m/Ps3، وتجنب أسرار ووجهات RPCS3 الخاصة.
احتفظ باختبارات upstream، ويمكن فصل job الاختبارات عن job تعبئة التطبيق. لا تحذف اختبارًا أو وظيفة لإخفاء فشل.
وثّق toolchain وQt وLLVM وVulkan SDK وباقي التبعيات المطابقة.
استخدم نشر Qt الصحيح: plugins والترجمات والموارد وDLLs وبقية التبعيات القابلة لإعادة التوزيع.
تحقق من Visual C++ runtime: وزعه محليًا إذا سمح الترخيص والبناء، وإلا وثق الحاجة والرابط الرسمي.
المستخدم النهائي لا يحتاج Python أو Visual Studio أو Terminal أو تعديل JSON/YAML.

المخرج:
MohammedLab-PS3-Windows-x64.zip
يحتوي EXE الحقيقي وجميع ملفاته المرافقة، ويعمل كمستخدم عادي بعد فك الضغط ضمن المتطلبات.
ارفع ZIP وSHA256 وتقرير الاختبارات كـartifacts. جهز إصدار Release يدويًا من build ناجح مع المصدر المطابق، دون نشر تلقائي لكل commit.
اعزل updater الخاص بـRPCS3 حتى لا يستبدل النسخة المعدلة بملفات upstream. التحديث اليدوي يكفي للإصدار الأول.

اختبر الحزمة المستخرجة بعيدًا عن مسارات Qt/Visual Studio الخاصة بالمطور، وتحقق من الموارد والتبعيات والتشغيل.
اختبر أول تشغيل وغياب firmware واليد والملفات غير الصحيحة وإلغاء اختيار ملف، وحفظ الإعدادات، والمسارات ذات المسافات والحروف العربية.
تحقق من وصول تشغيل اللعبة إلى المحرك الحقيقي.
شغّل PS3 homebrew مرخصًا مناسبًا إذا توفر، وسجل المصدر والاسم والإصدار والنتيجة.
اختبارات الألعاب التجارية محلية بملفات المستخدم: وثّق اسم اللعبة ومعرفها وإصدارها والإعدادات ومواصفات الجهاز ونتائج الصورة والصوت والتحكم.

جهز مصفوفة Windows 10/11، Intel/AMD CPU، NVIDIA/AMD/Intel GPU، مكتبي/لابتوب، لوحة مفاتيح/DualSense/XInput، Vulkan/OpenGL حيث تتوفر الإمكانات.
نفّذ الحالات الممكنة فعليًا، وميّز الباقي بوضوح بأنه لم يُختبر مع خطوات تحقق محلي. لا تدع اجتياز مصفوفة كاملة دون أدلة.
فرق بين compilation واختبارات الكود وفحص الواجهة واختبار GPU والمحاكاة واليد والألعاب. CI العادي قد يفتقر إلى GPU واليد وملفات المستخدم؛ نجاحه لا يثبت تشغيل الألعاب أو FPS.

## المصدر والترخيص
احتفظ بحقوق المؤلف وLICENSE وإشعارات الملفات وتراخيص التبعيات. أغلب RPCS3 تحت GPL-2.0-only وبعض الملفات بتراخيص أخرى.
اذكر في About وREADME أن البرنامج نسخة مستقلة معدلة مبنية على RPCS3 مع رابط المصدر الأصلي والمصدر المعدل.
لكل Release أرفق المصدر المقابل للbinary شاملًا recursive submodules والتعديلات ونصوص البناء وإعداد التبعيات. أرشيف GitHub التلقائي وحده لا يكفي.
نفذ العمل داخل moha700m/Ps3 فقط؛ لا ترسل issues أو PRs أو تعليقات تلقائية إلى upstream.
